# Unisys Training

Aplicación web de demostración para la gestión de incidencias y conocimiento,
con un frontend React/Vite y una API Express/MySQL.

El panel compara métricas de los tickets con gráficas creadas con Recharts.

Consulta las instrucciones de configuración en [backend/README.md](./backend/README.md)
y [frontend/README.md](./frontend/README.md). No guardes credenciales ni valores
locales de conexión en este repositorio.
